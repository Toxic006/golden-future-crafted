# Golden Future International School website

## Build scope
- Create a complete shared school website shell with the official crest, sticky desktop navigation, accessible dropdowns, animated mobile navigation, announcement strip, footer, and scroll-to-top control.
- Apply the selected Alpine Frosted Light direction: airy blue surfaces, deep institutional blue, restrained gold/red accents, Manrope and Space Grotesk, polished translucent panels, crisp spacing, subtle shadows, and measured motion.
- Use the uploaded school photography as the primary visual source, preserving aspect ratios and using responsive crops. Use the verified 23 staff portraits from the reference site for the faculty directory.

## Pages and content
- **Home:** immersive campus hero, welcome, verified school facts, learning pathway, facilities, four houses, leadership, staff preview, activities, timings, notices, and admissions call-to-action.
- **About:** school story, vision, mission, teaching philosophy, values, objectives, leadership messages, and development framework.
- **Academics:** Nursery–12 pathway, CBSE-aligned approach, learning methods, activities, wellness, assessment, parent engagement, and links to calendar/timings/fees.
- **Admissions:** 2026–27 classes, process, requirements guidance, fee information, admission enquiry form with validation and honest local success state.
- **Faculty:** all 23 verified staff members with names, roles, appointment dates, portraits, role filters, and consistent image treatment.
- **Facilities:** laboratories, playground, transport, health care, reception, administration, library/support, and safety using the correctly named supplied images.
- **Activities:** yoga, assembly, fire drills, first aid, safeguarding workshop, house system, and an accessible image gallery.
- **Information:** dedicated pages for timings, fees, houses, holidays, notices, governance, emergency contacts, and downloads where source material is verified.
- **Contact:** verified address and phone details, office hours, directions link, and contact form with validation and honest local success state.

## Shared experience
- Build reusable page headers, section headings, image cards, staff cards, calls-to-action, forms, accordions, galleries, and information tables.
- Connect every navigation item and call-to-action to a real route; omit the private admin portal from prominent public navigation while retaining a discreet footer link only if appropriate.
- Add unique titles, descriptions, Open Graph metadata, Twitter metadata, canonical links, and meaningful alt text to every public page.
- Add responsive behavior for desktop, tablet, and mobile with accessible keyboard states, reduced-motion support, lazy-loaded below-fold imagery, and no horizontal overflow.

## Technical approach
- Keep TanStack Start file-based routing and create every linked route in the same implementation batch.
- Define all colors, typography, shadows, gradients, and motion centrally as semantic design tokens.
- Store uploaded media through the project asset flow; optimize display dimensions and loading behavior.
- Keep forms front-end only because no submission service was requested; clearly confirm that enquiries are prepared but not transmitted.

## Verification
- Exercise all routes, desktop dropdowns, mobile nested navigation, forms, filters, and calls-to-action in the running preview.
- Check desktop and mobile screenshots, direct route refreshes, image loading/cropping, overflow, metadata, and browser console errors.
- Remove inaccurate reference placeholders, including the test notice and unsupported claims, before completion.
